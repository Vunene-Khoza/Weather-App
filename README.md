# Flat Weather App

A clean, minimalist, non-vibe-coded React Weather Dashboard featuring instant autocomplete via the Open-Meteo Geocoding Search API, browser-based current location detection, and dynamic animated weather GIF integration powered by Tenor.

## Features

- **Dynamic Tenor GIF Icon Mapping**: Replaced traditional static weather icons with contextual Tenor GIF embeds (e.g., Flying Cat in Sky for partly cloudy/overcast conditions, Elmo Thunder for storms).
- **Solid Black Visual Design**: Stripped of generic glowing boxes and gradients for a sleek, flat-black dashboard theme (`#000000`).
- **Precision Spacing & Sizing**: Structured typography and strict border-radius hierarchies (`12px` and `6px`).
- **Geolocation Quick-Link**: Fully integrated with browser location services to fetch coordinates automatically.
- **South African Regional Defaults**: Autocomplete search optimized with Cape Town and Durban regional suggestions.

## Available Scripts

In the project directory, you can run:

### `npm install`

Installs the required node packages.

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the production bundle inside the `build` folder.
